# aufgabensammlung

Collection of exercises related to statistics and similar fields. Useful for students.

This repository is the **master collection**: every exercise lives in `posts/<slug>/`, and `aufgaben_tabelle.tsv` is the master list (type, categories, chapter, and whether an exercise is published in the blog).

- Blog: [datenwerk](https://sebastiansauer.github.io/datenwerk/) (repo `datenwerk`). Its `posts/` folder is generated from here with `Rscript sync_datenwerk.R --apply`; do not edit it there.
- Also used as git submodule `exrs` in the `statistik1-aufgabensammlung` book.

See `CLAUDE.md` for the file format and the sync workflow.
